# Mobile-first com identidade de app nativo

## Status

Aprovado

## Contexto

O público do produto usa muito celular e precisa de uma experiência clara, direta e confortável, sem “desktop espremido”.

## Decisão

Adotar mobile-first como base, com bottom sheets para fluxos secundários e navegação compacta no celular.

## Consequências

- Melhor legibilidade e toque no celular.
- Exige ajustes específicos por tela.
- O desktop continua como camada expandida, não como base.

## Alternativas consideradas

- Reaproveitar o layout desktop com responsividade mínima.
