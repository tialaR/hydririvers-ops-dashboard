# Testing

## Comandos

- `npm run typecheck`
- `npm run lint`
- `npm run check:i18n`
- `npm run build`

**Baseline obrigatório antes de 🟢 em implementação** — ver `docs/agents/AGENTS-ZERO-REDEMOINHO.md`.

## Lab tests

- Testes versionados de UI Visual Lab **somente sob demanda** — usuário pediu, fluxo completo, integração ou alto risco.
- Evidência ad hoc em `output/ui-lab/<component>/` (não versionado) é o padrão.

## Checklist manual

- Teclado
- Foco visível
- Bottom sheets
- Tabs
- Timeline
- Formulários
- Mobile 360px / 390px / 414px / 768px
