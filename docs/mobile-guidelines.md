# Mobile Guidelines

## Princípios

- Começar pelo mobile.
- Usar uma coluna por padrão.
- Evitar tabelas e grids largos no celular.
- Preferir bottom sheets para filtros, busca, menus e detalhes.
- Manter touch targets de pelo menos 44px.

## Core Web Vitals e custo cognitivo

- Hierarquia visual clara — uma ação principal por tela quando possível.
- Densidade adequada ao contexto operacional (campo, embarque, negociação).
- Scroll previsível; respeitar safe-area e barra inferior.
- Animação **curta e útil** — não atrapalhar a tarefa; respeitar `prefers-reduced-motion`.
- Glass/transparência: validar sobre **fundo colorido e rolável**, não branco plano.

Ver `docs/agents/AGENTS-ZERO-REDEMOINHO.md` → **Core Web Vitals e custo cognitivo**.

## Microcopy

- Frases curtas.
- Linguagem simples e acolhedora.
- Explicar o próximo passo.
