# Tokens

## Cores

- `--bg`, `--surface`, `--text`, `--muted`, `--line`, `--brand`, `--warning`, `--danger`
- tema claro/escuro controlado por tokens de raiz e data-theme.

## Espaçamento

- Base de 4px/8px.
- Espaços compactos em listas e painéis operacionais.

## Radius

- `--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-xl`, `--radius-pill`

## Sombras

- `--shadow`, `--shadow-soft`

## Z-index

- `--z-header`
- `--z-bottom-nav`
- `--z-dropdown`
- `--z-popover`
- `--z-bottom-sheet`
- `--z-modal`
- `--z-toast`

## Breakpoints

- mobile: até 639px
- tablet: 640px a 1023px
- desktop: 1024px+
- wide: 1440px+
