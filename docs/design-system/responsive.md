# Responsividade

HydroRivers é mobile-first.

## Regras

- usar `min-width: 0` em contêineres flex/grid;
- evitar larguras fixas;
- evitar tabelas pesadas no mobile;
- bottom sheets em vez de modais/menus grandes;
- reservar espaço para bottom navigation;
- `clamp()` para títulos e valores fortes;
- touch targets mínimos de 44px;
- mapas e gráficos com versão compacta no mobile.
