# Design System

O design system HydroRivers prioriza densidade operacional, leitura rápida e comportamento coerente entre desktop e mobile.

## Princípios

- Sistema visual de operação, não de marketing.
- Tokens centralizados para tema claro e escuro.
- Componentes pequenos e previsíveis.
- Acessibilidade por padrão.
- Mobile-first com adaptação progressiva para desktop.

## Componentes base

- Button
- IconButton
- Card
- Badge
- Tabs
- Accordion
- BottomSheet
- Dropdown
- Tooltip
- Progress
- Switch
- Skeleton

## Componentes estruturais

- AppShell
- Header
- Sidebar
- MobileNav
- PageContainer

## Leitura rápida

- textos curtos;
- status sempre com cor + rótulo;
- cards compactos;
- bottom sheets para fluxos complexos no mobile;
- mapas com resumo textual acessível.
