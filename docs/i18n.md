# i18n

## Idiomas

- `pt-BR`
- `en-US`
- `es-ES`

## Regras

- **Proibido** hardcodar texto visível novo — placeholders, labels, `aria-label`, empty states, errors, CTAs, sheet titles.
- Criar chaves por domínio.
- Preferir traduções naturais, não literais demais.
- Atualizar **pt-BR**, **en-US** e **es** sempre que uma nova chave entrar.
- Rodar **`npm run check:i18n`** antes de fechar implementação.
- **Exceção:** `data-testid` e atributos técnicos de teste.
- **Operation Zero Redemoinho:** ver `docs/agents/AGENTS-ZERO-REDEMOINHO.md` → **Strings hardcoded proibidas**.
