# Dashboard

## Propósito

Exibir a visão operacional pública das cargas disponíveis na plataforma.

## Telas principais

- Dashboard público
- Detalhe de carga

## Componentes principais

- `operations-board`
- `dashboard-overview`

## Regras de negócio

- mostra cargas públicas;
- não depende exclusivamente do usuário logado;
- serve como visão de mercado/operação.

## Mobile

- mapa e detalhes em formato compacto;
- bottom sheets para filtros e ações;
- cards empilhados.

## Acessibilidade

- tabs acessíveis;
- mapa com descrição textual;
- botões com labels claros.
