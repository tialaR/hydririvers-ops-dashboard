# Minhas cargas

## Propósito

Exibir somente as cargas do usuário logado.

## Telas principais

- Lista de minhas cargas
- Detalhe da carga

## Componentes principais

- `my-cargoes-list`

## Regras de negócio

- usar `getMyCargos(currentUser.id)`;
- não repetir a lista pública do dashboard;
- linguagem voltada para a conta do usuário.

## Mobile

- cards compactos;
- CTA contextual;
- filtros por status em bottom sheet.

## Acessibilidade

- status textual;
- ações com labels;
- leitura clara do estado da carga.
