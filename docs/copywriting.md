## Exemplo de trocas

- `Previsão de atracação` -> `Chegada prevista`
- `Aplicar` -> `Ver resultado`
- `Limpar filtros` -> `Limpar escolhas`
- `ETA` -> `Tempo estimado`
- `Publicar carga` -> `Cadastrar carga`
